## 3. Referential Dependencies & Dependency-Safe Cleanup Plan

### Foreign-Key Dependency Graph

```
[products] ◄────────────── [product_variants] ◄────── [inventory_logs]
                                                             ▲
                                                             │ (references order_id)
[influencers] ◄─────────── [influencer_commissions]          │
     ▲                              ▲                        │
     │                              │                        │
     └────────── [orders] ──────────┴────────────────────────┘
```

1. `orders` is referenced as a foreign key by:
   - `influencer_commissions.order_id` (FK constraint)
   - `inventory_logs.order_id` (FK constraint `ON DELETE SET NULL`)
2. `influencers` is referenced by:
   - `influencer_commissions.influencer_id`
   - `orders.influencer_id`
3. `product_variants` is referenced by:
   - `inventory_logs.variant_id` (FK constraint `ON DELETE CASCADE`)
4. `products` is referenced by:
   - `product_variants.product_id` (FK constraint `ON DELETE CASCADE`)

### Dependency-Safe SQL Execution Sequence

If the store owner decides to clean all synthetic test data before going live, execute the cleanup in this **exact order** in Supabase SQL Editor:

```sql
-- STEP 1: Delete dependent influencer commission records (17 rows)
DELETE FROM influencer_commissions WHERE order_id IS NOT NULL;

-- STEP 2: Delete test inventory audit logs (123 rows)
DELETE FROM inventory_logs WHERE order_id IS NOT NULL OR reason LIKE '%Golden%' OR reason LIKE '%Test%';

-- STEP 3: Delete test admin audit logs (46 rows)
DELETE FROM admin_audit_logs WHERE entity_type = 'order' OR admin_email LIKE '%test%';

-- STEP 4: Delete synthetic test orders (220 rows)
DELETE FROM orders WHERE customer_email LIKE '%loozars-test.internal%' OR order_number LIKE '%LZR-%';

-- STEP 5: Reset coupon usage counters to 0 while keeping coupons intact
UPDATE coupons SET times_used = 0;

-- STEP 6: Reset daily order number sequence back to 1
ALTER SEQUENCE IF EXISTS order_number_daily_seq RESTART WITH 1;

-- STEP 7: Re-baseline inventory counts in product_variants to official starting inventory
-- (Example: Set starting inventory per SKU as required for Launch Drop 01)
```

> [!CAUTION]
> **Preservation Rule:**  
> Never run `DROP TABLE` or `TRUNCATE products` / `TRUNCATE product_variants` / `TRUNCATE coupons`.
